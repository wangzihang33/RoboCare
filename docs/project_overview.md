# 项目总览

智扫通智能客服系统是一个面向扫地机器人和扫拖一体机器人场景的智能客服 Agent。项目以 LangChain Agent 为核心，结合本地知识库 RAG、动态 Web RAG、工具调用治理和用户设备数据查询，支持售前咨询、使用指导、故障排查、维护保养、天气适配、品牌对比和个人使用报告生成。

## 项目能做什么

- 回答扫地机器人和扫拖一体机器人的产品知识、使用技巧、维护保养和故障处理问题。
- 基于本地知识库进行 Hybrid RAG 检索，支持向量检索、BM25、RRF 融合和 Reranker 重排。
- 在本地知识不足或用户询问最新产品、品牌对比时，调用 WebSearch 获取新鲜信息，并在回答中附带来源引用。
- 查询指定城市天气，结合湿度、风力、降雨等信息给出扫地/拖地机器人使用建议。
- 查询脱敏用户设备使用数据，生成清洁效率、耗材状态、同类对比和保养建议报告。
- 记录每次工具调用的输入摘要、输出摘要、耗时、状态、异常和拦截原因，方便审计和复盘。

## 核心模块

| 模块 | 作用 |
|---|---|
| Agent | 基于 LangChain `create_agent` 构建客服 Agent，负责意图判断、工具选择和最终回答生成。 |
| Local RAG | 使用 Chroma、Embedding、BM25、RRF 和 Reranker 检索本地产品知识库。 |
| Web RAG | 通过 Serper 搜索、网页抓取、URL 过滤、TTL 缓存和临时向量检索补充联网知识。 |
| Tool Hook | 在工具调用前后进行策略检查、日志记录、异常兜底和敏感信息拦截。 |
| Tool Service | 将 RAG、WebSearch、天气和用户数据查询封装为统一 LangChain 工具，并提供结构化错误。 |
| Evaluation | 基于业务 hard set 评估 Retriever 和 Generator，使优化过程有指标可对比。 |

## 项目亮点

1. **能证明效果的 RAG**：不仅能回答，还能通过 Recall@K、MRR、Faithfulness 和 Answer Relevance 评估不同检索策略。
2. **可追溯的联网补充**：WebSearch 不只是搜索后总结，还包含缓存、URL 治理、来源 metadata 和引用输出。
3. **可审计的工具调用**：工具调用链路具备 session、tool_call、耗时、错误和敏感信息治理。
4. **更真实的业务工具层**：天气查询使用真实 API，用户报告数据使用 SQLite，工具入参明确且可校验。

## 面试讲法

这个项目可以围绕四个点展开：

- RAG 评测与检索优化：用 hard set 和指标证明 RRF + Reranker 的收益。
- Hook 生命周期治理：把 Agent 工具调用变成可审计、可拦截、可复盘的过程。
- 动态 Web RAG：通过缓存、过滤、来源追踪和引用输出补充新鲜知识。
- 工具服务层标准化：统一工具输入校验、结构化错误、真实数据源和 LangChain 工具适配。
